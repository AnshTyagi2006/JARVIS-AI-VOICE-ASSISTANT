Capabilities

• 🎙️ Voice Recognition with wake word activation ("Jarvis")
• 🔊 Text-To-Speech responses with audio sound cues
• 🌐 Browser & YouTube automation ("Open YouTube", "Play Believer")
• 🌤️ Live weather reports via wttr.in
• 🤖 Optional OpenAI integration with free DuckDuckGo web search fallback

HOW TO USE

1. Tap the central Radar Core microphone icon or say "Jarvis".

2. Speak your command or type in the input box at the bottom left.

Voice Commands Cheat Sheet

Command JARVIS Action
"Jarvis"Activates listening mode
"Open YouTube" / "Open Google"Opens site in browser
"Play Believer"Plays requested song on YouTube
"Tell me the weather in Delhi"Fetches live weather
"What is the time?" / "What is the date?"Speaks current date/time
"Tell me a joke"Generates programming joke
"Search for Python tutorials"Runs a web search
